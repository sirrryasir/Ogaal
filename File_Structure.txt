# 3. HOW TO RUN (DO THIS NOW)

```bash
cd water-intelligence
conda env create -f environment.yml
conda activate water-intelligence
python -m app.main
```

Open browser: http://127.0.0.1:8000/docs

NB:-
1. api → talks to backend
2. domain → pure logic (AI brain)
3. services → orchestration
4. schemas → contracts (VERY important)
5. main.py → entry point
